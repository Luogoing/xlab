# XLAB · 专利研习 0.3.0

检索专利，读懂证据，形成研究判断。

本版面向项目成员在各自 Windows 电脑独立运行。新版实际操作和验证范围见 `docs/ACCEPTANCE.md`，五轮修改记录见 `docs/FIVE_ROUNDS.md`。

## 启动与停止

解压完整 Windows x64 便携包，双击 `启动专利研习.cmd`。完整包内置官方 Node.js 24.21.0 及许可证，无需安装开发依赖。浏览器地址默认为 `http://127.0.0.1:3000`。运行资料写入解压目录的 `.local`，请放在当前用户有写权限的普通文件夹。

重复启动复用同一目录的服务。端口被其他目录或版本占用时会明确报错，不会打开错误的项目。在 PowerShell 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Start-Xlab.ps1 -Port 3001` 可使用另一端口。

关闭浏览器不会停止服务。先在页面取消活动任务，再双击 `停止专利研习.cmd`。服务意外退出后，未完成任务标为中断，由用户明确重试，不自动调用外部服务。没有开机自启。

源码包不包含 Node 运行时和预构建前端。开发者需安装 Node 22.13 以上及依赖，先执行 `pnpm build:portable`，再运行 `node scripts/serve.mjs`。

## 首次连接

从“连接与设置”配置自己的 Patentics 凭据及模型授权。配置状态、安装状态和最近调用成功是不同状态；凭据存在不保证当前服务可用。

- Patentics：使用指定授权网关 `http://47.94.139.188:6006`，默认中国库 `cnapp`。当前网关采用 HTTP，DPAPI 仅保护本地存储，不代表网络传输已加密。
- Codex：使用当前 Windows 用户安装并登录的桌面 Codex。服务只从 `%LOCALAPPDATA%/OpenAI/Codex/bin` 发现满足版本要求的二进制，不使用 PATH 中的旧 CLI。默认 `gpt-6-astra`、中等推理、临时会话、只读、禁用工具；通过标准输入传入证据，JSON Schema 约束输出，单次最多 180 秒。
- 智谱：可显式选择 `glm-4.7-flash`，只有实际生成成功才显示核验成功；失败不会自动改用其他服务。

凭据在 `%USERPROFILE%/.codex/secrets/patent-lab` 由当前用户 DPAPI 加密，前端只接收配置存在性。模型子进程不继承数据源凭据。源码、便携包、项目备份不携带凭据。其他成员需配置各自授权。缺少模型时，关闭“首次检索前由 AI 整理关键词”和“取得资料后分析”，仍可获取、阅读、比较和编写报告。

## 一次研究的操作

1. 首页输入研究问题，选择了解技术路线、比较结构方案或进一步检索方向，创建项目。
2. 在“检索与阅读”执行检索。默认先由 AI 辅助整理词项；需要自行控制时展开条件，关闭自动策略并编辑关键词、日期和实际检索式。手写检索式进入手工接管状态，不被关键词修改覆盖。
3. 每轮默认 20 条候选、最多 5 篇可用详情，最多 20 次数据请求。按平台顺序去重，详情失败顺序补位。请求间隔至少 3.2 秒，并计入本机分钟、五小时和周额度；其他客户端用量仍由平台限流控制。临时服务错误最多重试一次，鉴权或限流错误停止。
4. 阅读正文、查找词语、记录笔记、钉选证据。引用可定位到对应记录与片段，原始 XML 用 SHA-256 稳定标识。仅题录候选可补充详情，不用于实质技术分析。不同来源版本保留差异，A/B 公开文本分别保存。
5. 在同一项目内复用查询，继续下一页或为候选补全文。修改查询后应从新一轮首页开始。平台返回重复页时停止补全文，避免重复消耗请求。平台命中数、本轮候选、取得正文和项目保留数分别显示。
6. “分析与复核”最多选择 20 篇，每批最多 5 篇、正文不超过 24,000 字符。输入优先覆盖摘要、独立权利要求、说明书及钉选片段，显示实际证据清单与遗漏范围。失败保留已成功批次，明确重试仅恢复未完成部分。
7. 引文编号、逐字引文与校验和通过，只说明引用有效。AI 推断仍需逐项采纳、驳回或改写；人工采纳不等于已证实。资料、筛选或策略改变后，关联分析过期。
8. “技术比较”选择 2—4 篇，按技术问题、核心结构、工作机制、应用条件和限制逐维度填写，支持增删维度及引用原文。资料缺失写明未找到依据，不推算性能排名。
9. “研究报告”按章节编辑、调整顺序、插入引用。保存版本或导出时冻结报告；Word、Markdown、JSON 使用同一报告编号与版本。历史报告保持原文字。“按当前资料重建草稿”会先保存旧草稿，再使用当前资料与分析生成新草稿。打印页面可通过浏览器“另存为 PDF”保存。

## 保存、备份与恢复

项目自动保存在本机，采用版本校验防止其他标签页覆盖。冲突时本页草稿保留，可载入最新版本或另存副本。地址使用 hash 路由，记录当前项目、页面、专利和证据位置，刷新无需服务器子页面路由。

“项目备份”下载完整 ZIP，包含项目 JSON、原始 XML、分析和历史报告，来源按哈希去重。导入前校验路径、容量与 SHA-256，失败保留当前项目。旧版本 1、2 JSON 继续读取，保留排除、理由、笔记、人工编辑及报告。缺少 XML 的旧备份明确标记来源缺失；恢复模型结果属于历史回放。

普通 JSON/CSV 输入上限 32 MiB，导入记录最多 2000 条；完整归档压缩后最多 256 MiB、展开后最多 512 MiB，单份 XML 最多 5 MiB。导出前检查回导容量。

`.local/projects` 保存项目及上一份 `.previous`；`.local/runs` 保存各次任务；`.local/source-assets` 保存原始来源；`.local/sources` 保留兼容来源路径。不要把 `.local` 当作公开发布内容，也不要用复制运行包代替项目备份。

## 开发与历史兼容

`pnpm install --frozen-lockfile` 安装开发依赖；`pnpm exec tsc --noEmit` 检查类型；`pnpm build:portable` 构建便携前端；`node --test tests/*.test.mjs` 运行测试。

独立业务核心位于 `core`，本机任务与项目服务位于 `server`，页面按职责拆分到 `components/xlab`。离线 CLI `node cli/patent.mjs` 与 MCP `node adapters/mcp-stdio.mjs` 保持可用。离线内置快照及导入资料不会标为本次实时采集。

完整包可执行 `node scripts/verify-handoff.mjs` 核对文件清单。运行时来自 Node 官方 Windows x64 发行包；其许可证位于 `runtime/LICENSE`，不提交大型运行时到源码仓库。

该应用用于阅读和研究判断，统计限于当前项目已取得资料；不构成专利有效性、侵权、授权概率或课堂效果结论。异机测试状态见验收文档。
