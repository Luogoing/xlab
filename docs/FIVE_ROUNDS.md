| 3 比较与分析 | 关闭自动分析后，单独点击分析也被跳过；删除维度再进入时选择框与正文不一致；窄屏比较前的完整选取列表过长。 | 显式分析独立于自动分析开关，增加回归测试；维度统一取有效项；已选列表折叠、移动导航不换行。两篇真实资料经页面分析、取消、重试成功，新增数据请求为 0；引用定位、采纳、排除后过期及撤销均复验。 |
| 4 报告与恢复 | 实际下载 Word/MD/JSON/ZIP，回导及双标签页竞争通过。双击保存出现多余冲突；规则问题列出所有片段导致旧草稿导出 52 页。 | 合并正在执行的保存请求，并以当前保存版本冻结；规则问题只列每篇代表片段。增加先保存旧版本再重建草稿。双击只新增一个版本，旧历史不变；当前分析重建后 Word 5 页、Chromium PDF 4 页。旧版 JSON 经浏览器导入，原始备份逐项一致。 |
| 5 便携交付 | 新解压目录内置 Node，无开发依赖启动。键盘建立拉挤项目，默认 AI 策略取得 5 篇真实详情。服务重连后旧错误仍残留。 | 独立连接提示恢复后自动消失，草稿保持原文；便携版阅读、笔记、比较、Word 下载通过。五篇分析两次超时后，明确选择两篇重新分析成功，额外取数 0 次；五篇均保留，报告与实际输入标明两篇分析范围。最终 Word 7 页。 |

桌面 1366×768、平板 820×1180、窄屏 390×844 均实际操作和截图。主流程没有自定义模态弹窗；笔记快捷入口将焦点放回正文输入区。两标签页竞争用 Playwright 延迟一个真实 PUT，另一页先保存，再放行旧请求；服务返回 409，本页草稿可另存。不是仅用接口模拟界面。
