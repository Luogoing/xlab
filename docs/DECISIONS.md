# 产品与工程决策记录

## 一、当前取舍

首版定位为工科学生的专利情报学习与科研主题探索，采用液氢储罐压力调节作为首个任务。该主题具有团队已有专业背景和明确结构要素，便于人工检查证据；锂电池液冷结构用于检查词表与流程的迁移条件。此定位仍属于需求假设，尚未获得学生访谈或实际课堂试用验证。

数据入口采用公开记录快照和用户导入，已经取得能够定位原文的8条公开记录。可访问网页与获准使用数据库接口具有不同条件，EPO、Lens和PQAI接入还涉及凭证、审批、费用或覆盖差异。首版保留数据适配接口，实时查询不作为当前可运行流程的依赖；具体核验依据见competitive_sources.md及data_sources.md。

业务逻辑采用独立ES模块，并由React网页、Node CLI和MCP测试入口复用。该选择使已构建运行包只依赖Node内置功能即可启动，避免课堂为规则处理安装Python环境；Word通过相同核心生成。已有环境提供完整pnpm锁定依赖及Vinext预览，原型实际复用该环境，另构建可移交的便携网页资源。

首版将数据模式与推理模式分别保存，模型配置缺失时显式使用规则处理。规则提取命中项、初步分类与研究问题模板，人工中文转述作为公开样本资料，具有独立标识；生成环节不把同一组预存结果伪装成不同新主题的模型推理。实时模型接入的触发条件为获得可用配置、明确数据授权，并通过引用与语义评价。

## 二、暂缓事项与继续条件

正式课堂试点、外部Agent宿主与公网发布均保留为未完成事项。当前没有已确认授课日期、学生人数或宿主安装环境，开源意向也尚未形成明确授权的仓库发布行动。交付先提供可检查代码、样本、运行包和课堂说明；后续集中确认一个实际课堂和一个目标宿主即可继续，不需要重新讨论全部技术选型。

进一步投入应以真实目标学生独立完成任务的能力和证据质量为依据。若主要困难集中在关键词构造，则优先完善检索教学；若主要困难为合法记录整理，则加强导入兼容性；若使用低频或已有工具已充分覆盖，则收缩同质化功能。账号、付费、复杂教师后台、大型知识图谱和多租户均暂缓，不把功能数量作为产品价值。
