实际能力边界：当前验证是同一台 Windows 电脑的干净目录，第二台真实电脑和不同账号尚未验证。智谱本轮未取得成功生成，不显示已验证可用。Codex 单次180秒超时后会保留资料，用户可以重试或缩小选择范围；不承诺每次五篇均能在该时间内生成。便携拉挤最后分析覆盖2/5篇，其余资料保留为可读资料。

浏览器点击“打印 / PDF”已触发原生打印流程，但系统打印对话框阻塞了自动控制；通过关闭该验收浏览器恢复。PDF内容与排版采用Chromium打印引擎文件及Word导出文件核验，未声称自动完成系统“另存为”对话框。

凭据与本机工作区不进入公开交付。递归检查源码及嵌套ZIP/Office文件，并扫描PDF文本；公开截图中无凭据输入。提供源码ZIP、Windows便携ZIP、项目组交接ZIP、使用说明、示例报告和脱敏操作记录。公开发布仅限 Luogoing/xlab 的授权范围。
