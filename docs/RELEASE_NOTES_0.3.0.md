# XLAB 0.3.0 版本变更

- 深色品牌导航与浅色阅读工作区，统一项目、检索、阅读、比较、分析复核和报告入口。
- 项目格式版本 3，支持多轮查询、笔记、钉选证据、比较及冻结报告，兼容旧版导入。
- 新建与重试共用串行入口；状态目录锁保护启动恢复；保存版本校验保留冲突草稿。
- 原始 XML 内容寻址，重试保留来源身份；不同文本版本保留冲突信息。
- 分批证据分析、失败批恢复及真实停止原因；实际输入与未读取范围可查。
- 完整项目 ZIP 以哈希校验、去重和容量限制保护导入，公开运行包不包含本机项目或凭据。
- Windows 便携包内置官方 Node.js 24.21.0；源码包不包含该二进制。

实际验证范围与限制见 ACCEPTANCE.md，五轮修改细节见 FIVE_ROUNDS.md。

浏览器迭代进一步修复显式分析被跳过、比较维度错位、重复冻结、过量规则引用、重连错误残留，补充笔记快捷入口、引用反馈和安全重建报告草稿。
